# 个人设置

- 个人模型、ASR 配置按用户 ID 存入 PostgreSQL；未启用个人配置时沿用 Sidecar 环境配置。
- API Key 使用服务端 RSA 私钥进行 JWE 加密，接口只返回是否已配置。部署备份需同时保留数据库与 `CREDENTIAL_PRIVATE_KEY_FILE` 指向的私钥文件。
- 模型配置用于 Agent 对话及会议纪要；ASR 配置由 API 验证会议归属后传给 Sidecar，浏览器只接收 60 秒有效的一次性票据。
- ASR 票据目前保存在 Sidecar 进程内，需单进程运行；扩展为多副本时需共享票据存储或配置连接亲和。
- 连接测试与保存分开。
- 外观偏好保存在当前设备，并按账号隔离。
