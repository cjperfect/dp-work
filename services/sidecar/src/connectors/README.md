# 飞书 Agent 工具

用户在连接器中完成授权后，Agent 自动获得 `feishu_search_documents`、`feishu_read_document`、`feishu_create_document`。工具固定使用当前账号的 CLI 配置和 user 身份，不接受任意命令、Shell、账号或本机文件路径。

搜索最多返回10条；读取只接受文档 token 或飞书 HTTPS 链接；创建仅接受标题和 Markdown 正文，通过受控临时文件传给 CLI，并接入现有工具人工审批。批准后执行，拒绝后不调用 CLI。工具失败或断流不自动重试创建，结果未知时先搜索核验。

授权登录请求 docs、drive 领域权限及基本身份权限，需要应用后台开通相应能力并由用户在飞书授权。此前仅授权身份的账号可在连接器重新授权。没有安装 CLI 或未验证授权的账号不挂载业务工具；当前电脑仍需安装官方 CLI（`pnpm setup:feishu-cli`）。

CLI 单次执行限制45秒，取消后终止子进程，结果最多展示30000字符。不提供发消息、删除文档或修改分享权限工具。本次自动测试使用 CLI 替身，不对用户飞书账号创建真实文档。
