项目是企业Agent平台：

1. 每个部门一个Agent，将部门业务范畴和SOP自动整理成skill，并内置业务专业技能skills，保证输出内容符合部门规范
2. 会议纪要：实时转换会议内容，结束会议后可以生成会议纪要，可以发出邀请链接给同事协同编辑，另外有react flow 查看会议重点内容结构，会议纪要可以转到对应的知识库里面
3. 知识库：用户自己建立自己的知识库，再对话里面使用@选择知识库
   架构： 基于 Electron Main、Renderer 与 Python Sidecar 分离桌面管理、聊天审批及 Agent 执行，通过 IPC、JSON-RPC 通信，并管理 Sidecar 生命周期，实现界面与执行服务解耦。
